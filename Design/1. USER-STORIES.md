## Central Authority

### Identity Management
- As the central authority, I want to be able to create new Digital IDs `so that` I can register citizens in the system
- As the central authority, I want to be able to alter the status of a Digital ID (active, suspended, or revoked) `so that` I can specify which Digital IDs can be queried by other organisations
- As the central authority, I want mutable attributes to be readable and modifiable `so that` the Digital ID can be kept up to date
- As the central authority, I want immutable attributes to be readable, but not modifiable `so that` core attributes cannot be modified, better reflecting the real world

### System Behaviour
- As the central authority, I want the system to reject requests to revoked or non-existent Digital IDs `so that` revoked Digital IDs have their states preserved and do not have unintended modifications
- As the central authority, I want the system to reject requests using a deterministic approach `so that` the system behaves in a consistent and predictable manner

### Auditing
- As the central authority, I want to view and filter a persistent log of all requests (accepted and rejected) on the system `so that` I can easily track changes
- As the central authority, I want the persistent log to include reasoning behind the changes `so that` the system complies with the Data Protection Act by documenting the justification for storing and modifying personal data

### Capabilities
- As the central authority, I want to be able to search or filter Digital IDs by attribute values `so that` I can locate specific citizens without knowing their Digital ID

## Other Organisations

### HMRC
- As HMRC, I want to be able to verify that a Digital ID was not suspended during a given reporting period `so that` I can confirm the Digital ID was active throughout the period before processing a tax return
- As HMRC, I want to be able to verify that a provided National Insurance number matches a Digital ID `so that` I can confirm the taxpayer's identity when processing their return without retrieving the stored value
- As HMRC, I want to be able to verify that a provided address matches a Digital ID `so that` I can send documents regarding tax operations to someone's home

### Employers
- As an employer, I want to be able to verify that a Digital ID is active `so that` I can confirm a Digital ID has not been revoked before processing a new hire
- As an employer, I want to be able to verify prospective employees' identities `so that` I can confirm new hires are who they say they are before hiring them
- As an employer, I want to be able to verify that a provided National Insurance number matches a Digital ID `so that` I can record the correct tax details with HMRC without retrieving the stored value
- As an employer, I want to be able to verify that a prospective employee meets a minimum age requirement `so that` I can ensure I am not employing someone below the legal working age for the role
- As an employer, I want to be able to verify that a provided address matches a Digital ID `so that` I can confirm contract and payroll details without retrieving the stored value

### Banks
- As a bank, I want to be able to retrieve the status of Digital IDs `so that` I can confirm a Digital ID has not been revoked before processing a new customer
- As a bank, I want to be able to verify customers' identities `so that` I can confirm customers are who they say they are before opening accounts
- As a bank, I want to be able to verify customers' ages `so that` I can determine if they are old enough for certain accounts as some financial services are age dependent
- As a bank, I want to be able to retrieve the address of a Digital ID `so that` I can send statements to the correct address
